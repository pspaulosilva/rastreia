# Atas de reunião

Uma ata por reunião (cliente, equipe, tutoria, cerimônia de sprint), escrita no mesmo dia. Nome do arquivo: `AAAA-MM-DD-tipo.md` (ex.: `2026-10-29-revisao-sprint-1.md`). Lição da devolutiva final do SR1: o processo só conta com registro feito enquanto acontece.

## Modelo

```
# Ata · <tipo> · <DD/MM/AAAA>

Presentes: <nomes>   Registro: <nome>   Duração: <min>

## Pauta
1. ...

## Decisões
| # | Decisão | Responsável | Prazo |
|---|---|---|---|

## Pendências e riscos
- ... (atualizar riscos.md se mudar probabilidade ou impacto)

## Próxima reunião
<data e pauta>
```
